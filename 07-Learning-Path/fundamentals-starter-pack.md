# Fundamentals starter pack

> The minimal curated link set to build basic understanding, then layer daily-practice topics on top. Start here; everything else builds on these.

## 0. The one-page mental model
- [Google ML Crash Course](https://developers.google.com/machine-learning/crash-course) — fast, pragmatic overview. *Start here.*

## 1. Maths → ML (visual intuition)
- [3Blue1Brown — Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra) — see vectors/matrices.
- [3Blue1Brown — Neural Networks (series)](https://www.3blue1brown.com/topics/neural-networks) — see backprop/gradient descent.
- [Seeing Theory (Brown)](https://seeing-theory.brown.edu/) — interactive probability/statistics.

## 2. Deep learning foundations
- [Karpathy — Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) — build a GPT from scratch; the best bridge from SWE to DL.
- [d2l.ai — Dive into Deep Learning](https://d2l.ai/) — free interactive book, code + maths.

## 3. NLP + transformers (your course area)
- [Hugging Face NLP Course](https://huggingface.co/learn/nlp-course) — the course you're following.
- [The Illustrated Transformer (Jay Alammar)](https://jalammar.github.io/illustrated-transformer/) — the canonical visual explainer.
- [Karpathy — Let's build GPT](https://www.youtube.com/watch?v=kCc8FmEb1nY) — video companion.

## 4. LLMs + practical engineering
- [Karpathy — Intro to LLMs](https://www.youtube.com/watch?v=zjkBMFhNj_g) — 1h talk, the whole field in outline.
- [Eugene Yan — Machine Learning System Design](https://eugeneyan.com/machine-learning-system-design/) — applied patterns + essays.
- [Lilian Weng (Lil'Log)](https://lilianweng.github.io/) — deep technical surveys (RAG, agents, RLHF).

## 5. MLOps + serving
- [Chip Huyen — Designing Machine Learning Systems](https://huyenchip.com/ml-interviews-book/) — systems thinking.
- [HuggingFace — Optimize LLM inference](https://huggingface.co/blog/optimize-llm) — cost/latency levers.

## 6. Staying current (low-noise)
- [Papers with Code](https://paperswithcode.com/) — papers + implementations.
- [Hugging Face Blog](https://huggingface.co/blog) — open-model ecosystem.
- [Sebastian Raschka — magazine](https://magazine.sebastianraschka.com/) — LLM fundamentals, rigorously.

## How to use this
Do 0 → 1 → 2 first (foundations). Then 3–4 as you follow the HF course. Then 5 when you ship, 6 ongoing. Each vault note already links to the relevant items in context — this page is the single hub.
