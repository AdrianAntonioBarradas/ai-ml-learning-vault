# Recommended resources

> Curated sites, channels, books, and papers for going deeper — low-noise, high-signal. Add your own as you find them; bump `last_reviewed`.

## Foundations
- [3Blue1Brown](https://www.3blue1brown.com/) — visual maths intuition (linear algebra, calculus, neural nets).
- [Seeing Theory](https://seeing-theory.brown.edu/) — interactive probability/statistics.
- [Dive into Deep Learning (d2l.ai)](https://d2l.ai/) — free book, code + theory.

## Deep learning / LLMs
- [Karpathy — Zero to Hero](https://karpathy.ai/zero-to-hero.html) — build neural nets from scratch.
- [The Illustrated Transformer (Alammar)](https://jalammar.github.io/illustrated-transformer/) — transformer visual.
- [Sebastian Raschka — magazine](https://magazine.sebastianraschka.com/) — rigorous LLM fundamentals.
- [Lilian Weng — Lil'Log](https://lilianweng.github.io/) — deep surveys (RAG, agents, RLHF).

## Applied / systems
- [Eugene Yan](https://eugeneyan.com/) — ML system design, testing, serving patterns.
- [Chip Huyen](https://huyenchip.com/) — ML systems + production.
- [Hamel Husain](https://hamel.dev/) — practical LLM/ML engineering.

## Frameworks / docs (reference)
- [Hugging Face Docs](https://huggingface.co/docs) · [LangChain](https://python.langchain.com/) · [LangGraph](https://langchain-ai.github.io/langgraph/) · [vLLM](https://docs.vllm.ai/) · [sentence-transformers](https://www.sbert.net/)

## Papers / current
- [Papers with Code](https://paperswithcode.com/) — papers + implementations, SOTAs.
- [arxiv-sanity](https://arxiv-sanity-lite.com/) — arXiv discovery.
- [Hugging Face Blog](https://huggingface.co/blog) — open-model ecosystem news.

## Videos / talks
- [Karpathy — Intro to LLMs (YouTube)](https://www.youtube.com/watch?v=zjkBMFhNj_g) — 1h field overview.
- [Andrej Karpathy YouTube channel](https://www.youtube.com/@AndrejKarpathy) — lectures + builds.

## Books (deeper)
- *Designing Machine Learning Systems* — Chip Huyen.
- *Probabilistic Machine Learning* (PML) — Kevin Murphy (free online).
- *Speech and Language Processing* — Jurafsky & Martin (NLP reference, free online).
