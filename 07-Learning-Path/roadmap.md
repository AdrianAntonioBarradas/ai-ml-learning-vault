# Roadmap

> An ordered path that leans on what you already know (applied maths + SWE) and skips what you don't need to relearn.

## The path

1. **Reframe what you know → ML language** (days)
   - [[what-is-ml]] → [[linear-algebra-for-ml]] → [[probability-statistics-for-ml]] → [[optimization-and-gradient-descent]].
   - You know the maths; this step is vocabulary + reframing.

2. **Core ML intuition** (week or two)
   - [[learning-paradigms]] → [[bias-variance-generalization]] → [[evaluation-metrics]] → [[feature-representations]].
   - Do the [[fundamentals-starter-pack]] links in parallel.

3. **Anchor to your own code** (ongoing)
   - [[02-PoC-Techniques/MOC-PoC-Techniques]] — you already built these; read each note against the file.

4. **LLM + tooling layer** (the course you're in)
   - [[04-LLM-Tooling/MOC-LLM-Tooling]] — LangChain, tools/agents, standardization.
   - Map to [[huggingface-courses-map]] as you progress.

5. **Inference + deployment** (when you ship)
   - [[03-Inference-Deployment/MOC-Inference-Deployment]] — serving, API architectures, multi-user concurrency.

6. **Chatbot engineering** (your active project)
   - [[05-Chatbot-Engineering/MOC-Chatbot-Engineering]] — apply it to your own chatbot project.

7. **Caveats + ops mindset** (continuous)
   - [[06-MLOps-Caveats/MOC-MLOps-Caveats]] + [[08-Consulting-and-Architecture/MOC-Consulting-Architecture]].

8. **Adjacent: web → components** (when relevant)
   - [[09-Web-to-Components/MOC-Web-to-Components]].

## Principle

Foundations first (steps 1–2), but keep returning to applied sections (3, 5, 6) as real work demands. Depth comes from the links; the vault keeps the structure and the connections. Update `last_reviewed` as you revisit.
